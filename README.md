# 坦克大战 · Tank Battle

一个使用原生 **HTML5 Canvas + JavaScript** 实现的坦克大战网页游戏。单文件、零依赖，双击 `index.html` 即可游玩。

## 玩法

- 控制你的坦克消灭所有敌军，同时**守住基地**不被摧毁。
- 砖墙可被击毁（开辟道路），钢墙无法摧毁，水潭能挡住坦克但挡不住子弹。
- 击毁敌军有几率掉落道具：

| 道具 | 效果 |
| --- | --- |
| ⭐ 火力 | 双发 + 更快弹速 |
| 🛡 护盾 | 短暂无敌 |
| ❤ 生命 | +1 生命 |
| 💣 手雷 | 消灭当前屏幕上所有敌军 |
| ⏱ 冰冻 | 冻结敌军 8 秒 |

- 每关消灭所有敌军即可进入下一关，敌军会越来越强（快速型、火力型、装甲型）。

## 操作

| 按键 | 功能 |
| --- | --- |
| `WASD` / `方向键` | 移动 |
| `空格` | 射击 |
| `P` | 暂停 |
| `M` | 音效开关 |
| `回车` | 开始 / 重新开始 |

## 运行

方式一：直接用浏览器打开 `index.html`。

方式二：本地起一个静态服务器：

```bash
cd 项目目录
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 在线体验

部署到 GitHub Pages 后，访问：

```
https://<你的用户名>.github.io/<仓库名>/
```

## 技术要点

- 原生 Canvas 2D 绘制，像素风格坦克与地图
- Web Audio API 合成音效（射击 / 爆炸 / 拾取）
- `localStorage` 保存最高分
- 瓦片地图 + 网格寻路式敌军 AI
